## Добрый день 👋

## Мои проекты

- [**Колосок**](https://kolosokmlt.ru) - сайт, разработанный и поддерживаемый мной.

- [**Расписание для ВУЗа**](https://github.com/MieSlie/schedule_pub) - WEB-приложения, которое автоматизирует процесс парсинга Excel-файлов и предоставляет каждому пользователю персонализированный доступ к расписанию через интуитивно понятный интерфейс.

- [**Мессенджер ALEX**](https://github.com/MieSlie/messenger_alex) - Полнофункциональный веб-мессенджер React + FastAPI с обменом сообщениями в реальном времени через WebSockets.

- [**SysManager**](https://github.com/MieSlie/SysManage) - Flask-приложение с веб-интерфейсом в виде сетки блоков, каждый из которых соответствует отдельному ПК в сети. Пользователь может выбирать один или несколько блоков, а затем выполнять для них массовые действия - подключаться по SSH/RDP, выключать ПК или отправлять команды.

- [**SQLET**](https://github.com/MieSlie/sqlet) - Python-библиотека для быстрого взаимодействия с SQLite и PostgreSQL. Содержит удобные методы для выбора, вставки, обновления и удаления данных через динамические объекты. Опубликована на PyPi, может быть установлена через pip. https://pypi.org/project/sqlet.
