## Мои проекты

- [**Расписание для ВУЗа**](https://github.com/MieSlie/schedule_pub) - WEB-приложения, которое автоматизирует процесс парсинга Excel-файлов и предоставляет каждому пользователю персонализированный доступ к расписанию через интуитивно понятный интерфейс.
- [**SQLET**](https://github.com/MieSlie/sqlet) - Python-библиотека для быстрого взаимодействия с SQLite и PostgreSQL. Содержит удобные методы для выбора, вставки, обновления и удаления данных через динамические объекты. Опубликована на PyPi, может быть установлена через pip. https://pypi.org/project/sqlet.
